以上为功能示意，不包含真实候选人资料。

01

双方说的话，分开显示

选择会议声音、耳麦麦克风或双方同时识别。按来源区分“面试官”和“我”，自己的话只做听译，不触发新一轮自动回答。

02

专业问题，结合自己的材料答

提前导入简历、汇报 PPT、论文和项目说明。提问时检索相关片段，结合方向与个人贡献组织回答，回答旁可查看来源。

03

结束后，回顾和复盘

手动保存或主动开启自动保存，在本机回顾与导出；对话记录不包含原始录音。

第一次使用

先做好这三件事，
再开始模拟面试。

  1. 安装 Windows 程序

    下载 Windows Setup 安装包，运行其中的安装脚本。无需 Python；已有 0.4.0 的用户可复用原目录中的运行库。

  2. 填写千问 Key，准备语音模型

    选择 qwen3.8-flash，在软件内填 Key，开启需要的翻译和回答用途，再点击“下载／检查语音模型”。

  3. 导入材料，检查双方收音

    导入自己的简历、PPT 或论文，选好 Zoom 输出和耳麦麦克风，再请同伴问几句英文，检查字幕与回答来源。
